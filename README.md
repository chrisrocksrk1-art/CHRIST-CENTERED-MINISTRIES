# Christ-Centered Ministries Mobile App

A complete React Native mobile application for Christ-Centered Ministries with 5 main sections.

## Features

- 📖 Daily Devotion
- 🎤 Sermons
- 🙏 Prayer Requests
- 📞 Contact Us
- 💝 Donate

## Installation

```bash
git clone https://github.com/chrisrocksrk1-art/CHRIST-CENTERED-MINISTRIES.git
cd CHRIST-CENTERED-MINISTRIES
npm install
npm start
```

Then scan the QR code with Expo Go on your phone!
